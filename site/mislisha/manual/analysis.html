Analyse a position or a game

One position, looked at properly: the engine's opinion, what masters have played, and a tree of the variations you try. It is also where a line you like becomes part of a tutorial.

Open it

Library tab → Open Analysis. The card describes it as it is: Engine, opening database, and variation tree — for working on a single position or game.

Get a position onto the board

  • Board Setup puts pieces where you want them, with the side to move and Castling: rights; Clear board 🗑️ empties it first.
  • A game can be pasted or opened as a PGN file, or fetched from Chess.com/Lichess with Download Games.
  • Anything in your library — a saved position, a game of your own — can be loaded onto the board.

The engine

Stockfish runs on your own machine, and the panel beside the board shows what it thinks and the lines it is considering. Which panels you see is your choice, in Settings under the board's appearance; the engine itself is configured there too, with Configure local engine for a Custom local engine (.exe) if you have one.

Automatic Position Analysis walks a whole game instead of one position, and Blunder detection is what marks the moments worth talking about. It can be told Analyze only from the current position forward when the opening is not the point.

The opening database

For a position early in a game, the explorer says what has actually been played there and how it turned out, counted over master games in which both players were rated 2200 or more. The book covers the first 50 plies of those games; for a position deeper than that, it says so rather than showing an empty list. You need to be signed in to see it.

The tree of what you tried

Every move you play is kept as a branch rather than replacing what was there, so trying a second idea does not lose the first. On a move in the tree: Set as main line promotes a variation, Delete this variation removes one, and Delete this move (and branch after it) takes back a single move with everything under it.

Words go on a move with Add Comment — later Add / Edit Comment — and NAG Symbols (!, ?) add the usual annotation marks. Generate AI comment offers a sentence about the position if you want a starting point.

Keep it, or teach from it

Save analysis keeps the tree in your library so you can come back to it.

To turn it into teaching material, press Use in a tutorial and pick one of its rows. New tutorial from this position and New tutorial from this line start a fresh tutorial in the Tutorial Studio; New tutorial from this game does the same with the whole game, letting the engine and the words route do the work. Add this position to a tutorial… and Add this line to a tutorial… add one step to a tutorial you already have — for a line, it also asks Where does the step begin?: From here, where you are standing, or From start of line. Open a tutorial to edit… opens one you already wrote. What arrives in the studio is a part you can write on; see writing a tutorial.

What can go wrong

  • Saving asks you to sign in — analysis is kept on the server, so a guest cannot save it.
  • A PGN will not open — Cannot read file contents. means the file is not readable text; paste the moves instead.
  • The engine says nothing — it is still starting up (Calculating moves...), or the panel is switched off in Settings.
